# Resume CLI logo – usage guide

**Concept:** a document with a CLI prompt (`>_`): data in, resume document out.

| Item | Value |
|---|---|
| Brand colour | Indigo `#4338CA` (rgb 67 56 202) |
| Wordmark colour | `#111827` |
| Wordmark | `resume-cli`, JetBrains Mono Bold, converted to outlines |

## Files
- `source/symbol.svg`, `source/symbol-small.svg` (use below 24 px), `source/lockup-horizontal.svg`
- `symbol-{black,white,mono-4338ca}.svg`, `lockup-horizontal-{black,white,mono-4338ca}.{svg,png}`
- Web icons: `favicon.ico`, `favicon.svg`, `favicon-{16,32,48}.png`, `apple-touch-icon.png`, `icon-{192,512}.png`, `maskable-512.png`, `site.webmanifest`, `head-snippet.html`
- `concepts/`: the three explored directions (A R-block, B data to page, C doc prompt; C chosen)

## Rules
- Clear space: at least the width of the prompt cursor block (about 1/10 of the symbol height) on all sides; 1x symbol height around the lockup is comfortable.
- Minimum size: symbol 16 px (use the small cut), lockup 120 px wide.
- Backgrounds: colour on white or light grey; white version on indigo/dark; black or mono for one-colour print.
- Don't: recolour outside the palette, stretch, add shadows/gradients, rotate, or retype the wordmark in another font.

## Notes
- Not trademark-cleared; run a search before commercial use.
- Wordmark font is JetBrains Mono (OFL), outlined.
- The blog's own favicon in `content/public` is untouched. To use this on the product page, copy the web icons and `head-snippet.html` entries when you decide where they should live.
